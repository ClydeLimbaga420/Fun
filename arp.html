2 — Why the MAC address changes at each hop

frame, relabeled at each hop

A frame's MAC addresses only have to make sense for the current wire — each device that forwards it swaps in a fresh source/destination MAC pair for the next hop. The IP addresses are different: they identify the original sender and the final destination, so they stay the same for the whole trip, all the way to the outside server.

3 — ARP poisoning (man-in-the-middle)

forged ARP reply intercepted traffic

ARP has no authentication — any host can claim to own any IP. In this attack the attacker sends forged, unsolicited ARP replies to both the victim and the gateway: it tells the victim "I'm the gateway" and tells the gateway "I'm the victim." Both caches update, and traffic that should flow straight across the LAN now detours through the attacker.

Mitigations used in real networks: static ARP entries for critical hosts, Dynamic ARP Inspection on managed switches, port security, and encrypted transport (TLS) so an intercepted packet still isn't readable.
